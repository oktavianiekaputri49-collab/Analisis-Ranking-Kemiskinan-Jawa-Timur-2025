# Analisis-Ranking-Kemiskinan-Jawa-Timur-2025
Project ini membahas analisis persentase kemiskinan kabupaten/kota di Jawa Timur tahun 2025 berdasarkan data Badan Pusat Statistik (BPS). Analisis dilakukan untuk mengetahui ranking daerah dengan tingkat kemiskinan tertinggi hingga terendah serta melihat perbedaan kondisi sosial ekonomi antar wilayah.
